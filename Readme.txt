Точный, адаптивный и эстетичный инструмент для расчёта траектории пули в реальных условиях.  Как это работает — баллистика и логика
🔹 Основная модель
Расчёт траектории основан на модифицированной формуле сопротивления воздуха по Г1/Г7 (в зависимости от формы снаряда), с учётом переменной плотности атмосферы по высоте.

Используется численное интегрирование методом Рунге–Кутты 4-го порядка для решения дифференциальных уравнений движения:
dx/dt = vx  
dy/dt = vy  
dvx/dt = -k ⋅ v ⋅ vx  
dvy/dt = -g - k ⋅ v ⋅ vy
где:

v = √(vx² + vy²) — текущая скорость,
k = (ρ ⋅ Cd ⋅ A) / (2 ⋅ m) — коэффициент сопротивления,
ρ — плотность воздуха (зависит от высоты, температуры, давления),
Cd — коэффициент лобового сопротивления (G1/G7 BC),
A — площадь поперечного сечения пули,
m — масса пули,
g — ускорение свободного падения (корректируется по широте/высоте).

## ✨ Основные функции

Приложение выполняет расчёт траектории по модели сопротивления G1 или G7 с использованием численного метода Рунге–Кутты 4-го порядка.

В расчёте учитываются:
- Калибр, масса и баллистический коэффициент пули (BC G1 / G7)  
- Начальная скорость и дульная энергия оружия  
- Дистанция до цели  
- Угол наклона стрельбы (например, при охоте в горах)  
- Высота над уровнем моря  
- Метеоусловия: температура, атмосферное давление, влажность, ветер (горизонтальный и вертикальный компоненты)  

По результатам расчёта приложение возвращает:
- Поправку по вертикали и по горизонтали (в MOA, MIL или сантиметрах — на выбор)  
- Время полёта пули  
- Остаточную скорость и энергию на дистанции  
- Превышение траектории и снос от ветра  

Для удобства реализованы вспомогательные функции:
- `matchAmmoToWeapon()` — по выбранному оружию автоматически подбираются подходящие боеприпасы и их параметры (V₀, масса, BC)  
- `autoFillWeather()` — один клик — и поля температуры, давления, влажности и ветра заполняются данными с OpenWeatherMap  
- `getSunTimes()` — расчёт восхода/заката по вашим координатам; на его основе работает автоматическая смена темы  

Результат можно сохранить в профиль пользователя или экспортировать как таблицу (в будущем — PDF/CSV).

## 🌍 Автоматизация — чтобы меньше думать, больше стрелять

Вы можете вручную вводить всё — но зачем? Приложение умеет:
- Определять ваше местоположение (широта, долгота, высота)  
- Автоматически запрашивать погоду для этих координат  
- Рассчитывать плотность воздуха с учётом высоты, температуры, давления и даже влажности  
- Переключать тему интерфейса на «ночную» после заката и обратно — утром  

Все числовые поля принимают **точку**, а не запятую, как десятичный разделитель — по вашему предпочтению.

## 📱 Экраны и интерфейс

**Главный экран** — это меню: «Расчёт», «Профиль», «База данных», «Настройки». Дизайн построен на Material 3, с адаптивными шрифтами и цветами. Интерфейс не перегружен: показываются только поля, необходимые для текущего сценария.

**Экран расчёта** — центр приложения. Он разделён на логические блоки:  
- *Оружие*: выбор из списка (ввод вручную запрещён — только предопределённые варианты)  
- *Патрон*: после выбора оружия список автоматически сужается до совместимых боеприпасов  
- *Цель*: дистанция, угол наклона, высота  
- *Погода*: кнопка «Авто» вызывает `autoFillWeather()`; при отсутствии интернета — последние закэшированные значения или выбор из часто используемых значений  
- *Настройки вывода*: единицы измерения (MOA/MIL/см), формат сохранения  

**Экран профиля** хранит историю расчётов, часто используемые дистанции, предпочтения. Можно переключаться между профилями — например, «Охота» и «Соревнования».

**Админ-панель** (доступна только пользователю с ролью `ADMIN`) позволяет:  
- Просматривать содержимое базы данных  
- Добавлять новые модели оружия и боеприпасы  
- Создавать новых клиентов (пользователей) и назначать им роли  
- Проверять версию БД и количество записей  

**Настройки** — здесь можно:  
- Изменить API-ключ погоды (локально, без коммита)  
- Включить/выключить автоопределение местоположения  
- Выбрать модель сопротивления по умолчанию (G1 или G7)  
- Настроить поведение темы («Всегда светлая», «Всегда тёмная», «Авто»)

## 🛠 Инструкция по использованию

1. **Первый запуск**  
   Приложение создаёт три учётные записи: два обычных пользователя и одного администратора. Для входа в админ-панель используйте учётную запись `admin` (пароль задаётся при первом входе или берётся из настроек).

2. **Расчёт траектории**  
   • Откройте раздел *Расчёт*.  
   • Выберите оружие из списка — подтянутся совместимые патроны.  
   • Укажите дистанцию и, при необходимости, угол наклона.  
   • Нажмите «Авто» — приложение получит ваше местоположение и погоду.  
   • Нажмите «Рассчитать».  
   • Результат отобразится в виде краткой сводки и подробной таблицы. Нажмите «Сохранить», чтобы зафиксировать расчёт в профиле.

3. **Работа с админ-панелью**  
   • Перейдите в *База данных* → *Админ-панель*.  
   • Добавьте новое оружие: укажите марку, модель, калибр, начальную скорость.  
   • Привяжите к нему боеприпасы: масса в граммах, BC (G1/G7), длина.  
   • Создайте нового пользователя — например, для клиента или коллеги по стрельбищу.

4. **Настройка погодного API**  
   • Получите бесплатный ключ у [OpenWeatherMap](https://openweathermap.org/api).  
   • Поместите его в файл `local.properties` в корне проекта:  
     ```
     API_WEATHER_KEY=ваш_ключ_здесь
     ```  
   • Этот файл исключён из Git — ваши ключи в безопасности.

При отсутствии интернета приложение использует кэш последнего успешного запроса или позволяет выбрать погоду из ограниченного списка часто используемых значений — ручной ввод чисел отключён, как и планировалось.

## 🧪 Технологии и реализация

Проект написан на Kotlin с использованием архитектуры MVVM и Repository Pattern.  
Хранение данных — через Room: база создаётся автоматически при старте, без ручного SQL.  
Геолокация — через FusedLocationProvider из Google Play Services.  
Интерфейс — полностью на Jetpack Compose: каждый экран — отдельный модульный файл, переносимый и тестируемый.  
Темы, анимации и адаптивность реализованы в рамках Material 3.  
Расчётная часть вынесена в отдельный модуль `ballistics-core`, что позволяет в будущем протестировать её на JVM или даже использовать в CLI-версии.

## 📚 Научная основа

Базовая модель — модифицированная баллистика с учётом реальной атмосферы. Плотность воздуха корректируется по высоте, температуре, давлению и даже влажности (вклад ~0.3% при 90% влажности — но мы учитываем).  
Ускорение свободного падения корректируется по широте и высоте.  
Учёт ветра — через векторное сложение с начальной скоростью.

За основу взяты проверенные источники:  
- *Applied Ballistics for Long-Range Shooting* (Bryan Litz)  
- Алгоритмы JBM Ballistics  
- Стандарты MIL-STD-3017 по формату данных
